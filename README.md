## 📝 My Problem Solving Rules
문제를 풀 때 다음 3가지 원칙을 지키려고 노력합니다.
1. **문제의 본질 파악:** 코드를 짜기 전, 요구사항과 제약 조건(시간, 메모리)을 먼저 꼼꼼히 분석합니다.
2. **다양한 접근 방식 고민:** 하나의 방법으로 풀렸더라도 더 나은 자료구조나 알고리즘이 없는지 리뷰합니다.
3. **가독성 높은 코드:** 변수명을 직관적으로 짓고, 로직이 복잡한 부분은 주석으로 의도를 남깁니다.
